# Task Manager

Десктопное приложение для управления задачами с графическим интерфейсом на Tkinter.

## Запуск приложения
1. Убедитесь, что установлен Python 3.x.
2. Откройте проект в Visual Studio 2022.
3. Установите `gui.py` как запускной файл и нажмите `Ctrl + F5`.

## Функциональность
- Добавление задач с указанием названия, описания и срока выполнения.
- Просмотр имеющихся задач в интерактивном списке.
- Удаление выполненных или ненужных задач.
- Автоматическое сохранение и загрузка данных из файла `tasks.json`.
